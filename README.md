I am a software engineer driven by curiosity about how things work under the hood. I don't stick to a specific stack or niche; I prefer to use whatever tool best solves the problem at hand or allows me to explore a new layer of the computing system.

I tend to jump between whatever technologies catch my interest, which usually means a mix of building for the web and messing around with system-level tools. Most of what I write is either a response to a curious "how does this work?" or a practical solution for a problem I or a friend ran into. One day it might be a React or Next.js interface, and the next it’s writing Python for video processing or using C++ to see how raw TCP/UDP sockets behave.

I have a real interest in the deeper side of things, diving into game development, understanding how kernels manage hardware, or figuring out the nuances of multi-threading and concurrency. I’d rather have the freedom to explore the whole stack, whether that involves optimizing a complex SQL or NoSQL database schema or writing a script to automate something tedious.

To me, the language or platform is just a tool to bridge the gap between a high-level UI and the logic running beneath it.

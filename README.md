Software engineer in Egypt. I like building small, polished tools and understanding the layer underneath them.

**Things I've built**

- [Artiseal](https://github.com/medovanx/Artiseal): right-click a downloaded file to see where it was really built (GitHub build provenance, Sigstore).
- [Data Tide](https://github.com/medovanx/data-tide): network speed in the Windows taskbar, a daily usage log and per-app speed limits.
- [Salaty Reminder](https://github.com/medovanx/salaty-reminder): prayer times in the taskbar, with adhan and Hijri calendar.
- [Sky Glance](https://github.com/medovanx/sky-glance): weather in the taskbar, several cities and any date since 1940.
- [Sunplus Channel Studio](https://github.com/medovanx/sunplus-channel-studio): channel list editor for Sunplus satellite receivers.
- [MIMESIS patches](https://github.com/medovanx/mimesis-patches): 10-player lobbies for MIMESIS without a mod loader.

Mostly C# and .NET on Windows, TypeScript and Next.js on the web, some C++ and Python.
